# Every version of the agent files Imark has ever shipped, one line per version:
# the SHA-256 of the file as it lives in plugin/, followed by the name it takes
# inside the app bundle's agent folder.
#
# It exists so that the app can tell its own stale copy from somebody's edit.
# When a new version rewrites the copies in ~/.claude and ~/.codex it only
# touches a file whose contents are on this list — that file is ours, nobody's
# work is in it, and it can be replaced without asking. Anything else is an edit
# somebody made, and an edit is theirs to keep even when it is out of date.
#
# build.sh appends the hash of whatever it is about to put in the bundle, so a
# release records itself. Lines are never removed: a line that goes away is a
# person whose old copy stops being recognised and stops being brought forward.
#
# The hashes are of the file with `${CLAUDE_PLUGIN_ROOT}` still in it, which is
# what the installer puts back before hashing an installed copy — otherwise the
# same shipped file would hash differently on every machine, depending on where
# the app happens to live.
